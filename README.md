# Mental Wellness Daily Check-In and Mood Tracking Telegram Bot

A Telegram bot for mental health apps, therapy practices, and wellness communities. Sends personalized daily mood check-ins using validated PHQ-9 and GAD-7 scale prompts, tracks mood trends over time, detects distress patterns and surfaces resources, sends reminders for meditation and journaling habits, and delivers weekly wellness summary reports to users and optionally to their care team. HIPAA-ready with data export.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
